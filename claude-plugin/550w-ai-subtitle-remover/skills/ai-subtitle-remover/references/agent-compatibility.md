# SkillHub.club edition

This edition is sized for SkillHub.club's 100 KB ZIP limit. It includes the same global CLI actions as the full edition, with English as the default and Eraser account setup. It does not bundle the MCP server. Run one JSON request at a time with `node {baseDir}/dist/550w-skill.cjs` and parse its JSON response. Provide `SUBTITLE_REMOVER_USER_NO` and `SUBTITLE_REMOVER_API_KEY` in the host environment, or use `configureCredentials`. Install Node.js 18 or newer; direct public video-file URLs additionally require `ffprobe`.

The full local MCP distribution is available from the [ClawHub listing](https://clawhub.ai/sunshinehu/skills/550w-ai-subtitle-remover). Do not describe this compact edition as an MCP server.
